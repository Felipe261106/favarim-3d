# Favarim 3D Hub

Crie um site completo, moderno e responsivo para uma loja online de produtos para impressão 3D chamada "Favarim 3D".

### Objetivo

O site deve transmitir profissionalismo, confiança e tecnologia, oferecendo uma experiência semelhante às grandes lojas de e-commerce.

Utilize:

- HTML5

- CSS3

- JavaScript puro (sem frameworks)

- Código organizado e comentado

- Design moderno

- Responsivo para celular, tablet e computador

Paleta de cores:

- Branco (#FFFFFF)

- Preto (#111111)

- Azul (#1E88E5)

- Cinza claro (#F5F5F5)

Tipografia moderna (Google Fonts - Poppins).
